
# Gestión de supermercado

El programa se encarga de gestionar la creación y el manejo de entidades utilizando patrones de diseño reconocidos para facilitar su mantenimiento y escalabilidad. En concreto, implementa el patrón Factory Method para la generación de identificadores y la creación de distintos productos, lo que permite una abstracción en la instanciación de objetos; y utiliza el patrón Singleton para delimitar las cajas, asegurando que esta funcionalidad cuente con una única instancia durante la ejecución del programa y ofreciendo así un control centralizado del recurso.

## Para correr el programa "Supermercado"
- Entrar a "src" con `cd src`
- Correr el programa con el comando `java Supermercado`

## Para parar la simulación:
